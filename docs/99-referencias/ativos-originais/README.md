# Ativos originais da marca

Colocar aqui os arquivos recebidos da cliente, preservando os originais sem compressão ou edição destrutiva.

## Estrutura sugerida

```text
ativos-originais/
├── logo/
├── fotografias/
├── livros-e-publicacoes/
└── identidade-visual/
```

## Logo

Prioridade de recebimento:

1. SVG, AI, EPS ou PDF vetorial;
2. PNG com fundo transparente e alta resolução;
3. versões horizontal, vertical, monocromática, clara e escura;
4. manual de identidade, se existir.

## Fotografias

- arquivos originais em resolução máxima;
- versões sem filtros destrutivos;
- informação de autoria e autorização de uso;
- não renomear nem sobrescrever o arquivo original;
- incluir fotos verticais e horizontais disponíveis.

## Publicação no site

Estes arquivos não serão servidos diretamente. Durante a construção, cópias selecionadas serão recortadas, renomeadas e otimizadas para `public/images/`, mantendo os originais nesta pasta como referência.
